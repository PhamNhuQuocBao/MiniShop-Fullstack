# Tự triển khai Render + MongoDB Atlas

Không có tài nguyên cloud nào được tạo bởi agent. `render.yaml` định nghĩa **hai Web Service Node** với root directory `frontend` và `backend`, build bằng `npm ci && npm run build`, start bằng `npm start`, health path `/api/health`. Không dùng Render Static Site. Node được pin bằng `NODE_VERSION=22.18.0`. Cấu trúc `rootDir`, `buildCommand`, `startCommand`, `healthCheckPath`, `envVars` đối chiếu với [Render Blueprint spec](https://render.com/docs/blueprint-spec) và [Node version](https://render.com/docs/node-version) (truy cập 2026-11-01).

1. Tạo cluster Atlas theo gói bạn chọn, database user và IP access list theo [hướng dẫn Atlas](https://www.mongodb.com/docs/atlas/connect-to-database-deployment/?interface=atlas-ui). Lấy URI kết nối ứng dụng dạng `mongodb+srv://.../minishop?...`; bảo quản ở Render BE, không đưa vào FE/repo. Cấu hình network access phù hợp đường ra thực tế của Render.
2. Tạo hai Web Service từ Blueprint hoặc thủ công. BE: `MONGODB_URI` là URI Atlas, `JWT_SECRET` là chuỗi ngẫu nhiên ít nhất 32 ký tự, `CORS_ORIGINS` là URL FE thực tế. `PORT` do Render cấp. FE: `API_BASE_URL` là URL HTTPS public của BE hoặc địa chỉ nội bộ phù hợp nếu gói Render của bạn hỗ trợ; FE gọi từ server. Không cần `NEXT_PUBLIC_API_BASE_URL` vì browser không gọi BE trực tiếp. Không đặt secret trong biến `NEXT_PUBLIC_*`.
3. Deploy BE trước; health `/api/health` phải trả 200 khi nối MongoDB. Seed **một lần** bằng môi trường an toàn có URI Atlas và hai biến `SEED_CUSTOMER_PASSWORD`, `SEED_ADMIN_PASSWORD`: `cd backend && npm ci && npm run seed`. Không đưa mật khẩu seed vào source. Nếu dùng môi trường BE để chạy seed, nhập biến qua quản lý secret của nền tảng. Không chạy seed/reset trong start command.
4. Điền URL BE vào `API_BASE_URL` của FE, deploy FE. Sau khi có URL FE, điền chính xác origin đó vào `CORS_ORIGINS` BE nếu cần; ở bản này request từ Next server không bị CORS browser ràng buộc. Thay `API_BASE_URL` cần redeploy FE. FE health chỉ xác nhận Next server còn chạy; BE health xác nhận DB.

Render có thể có cold start theo gói đã chọn; lần tải đầu sẽ chậm. Kiểm tra giới hạn, giá và network của gói hiện tại trước khi tạo tài nguyên. Không lưu MongoDB trên filesystem tạm của Web Service. Password seed dùng cho demo; thay trước khi public. **Cảnh báo bảo mật:** Next 15.5.15 được pin cho lab tái hiện CVE và **vẫn dính 5 CVE** (xem [lab-cve-reproduction.md](lab-cve-reproduction.md)). Không deploy bản này lên Render/public. Muốn deploy thật, nâng Next lên `>=15.5.21`, chạy lại lockfile/build, và đảm bảo `LOCAL_CVE_MODE` không được set trên Render (không dùng `build:study`/`start:study`/`seed:lab`). Tài liệu này không khẳng định dịch vụ đã được triển khai hay kiểm thử.

Nếu dùng custom domain khu vực, thêm `REGION_HOSTS` vào biến môi trường **trước build FE** dưới dạng JSON, ví dụ `{"shop.example.us":"us","shop.example.eu":"eu"}`. Cấu hình domain/DNS về FE trong Render; rewrite dựa trên Host của request. Không set biến này nếu chỉ dùng prefix `/us`, `/eu`, `/vn`. Seed backend tạo 3 partner với tracking URL placeholder; cần thay URL bằng URL đối tác thật trong DB trước khi dùng.
