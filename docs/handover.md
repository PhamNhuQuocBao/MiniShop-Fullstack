# Bàn giao

Đã viết source FE Next.js 15.5.15/React 19.0.0 và BE Express/Mongoose, sản phẩm, tìm kiếm, chi tiết, giỏ backend/cookie ký, checkout, login/logout, account, admin; MongoDB models, seed upsert, reset có xác nhận; Dockerfile, Compose và Blueprint Render hai Web Service. Node local được ghi nhận: 22.18.0. Các phiên bản dependency chính nằm trong package.json và lockfile từng app.

Build trên Node.js 22.18.0/npm 10.9.3: `backend: npm run build` thành công; sau khi nâng cấp cho lab, `frontend: npm ci` và `npm run build` thành công, Next.js xác nhận version 15.5.15 (`build:study` cũng thành công). React/React DOM 19.0.0 vẫn được pin. npm cảnh báo dependency có lỗ hổng, và Next 15.5.15 **vẫn dính cả 5 CVE lab** (44580, 44575, 64645, 44576, 64641) — bản này phục vụ môn học, **không deploy public**; muốn deploy thật phải nâng Next `>=15.5.21` và tắt `LOCAL_CVE_MODE`. CVE-2025-29927 đã vá từ 15.2.3 nên không còn tái hiện. Theo yêu cầu, **chưa viết/chạy test, smoke test, E2E hoặc kiểm thử thủ công; chưa chạy app hay seed; chưa deploy hay tạo Atlas/Render**. Vì vậy chưa khẳng định luồng nghiệp vụ chạy thành công ngoài biên dịch.

Người dùng cần: tạo Atlas, cấu hình URI và network/user; điền `JWT_SECRET`, hai mật khẩu seed, `API_BASE_URL` và `CORS_ORIGINS`; seed một lần; tự deploy BE và FE theo [deployment.md](deployment.md). Tài khoản email mẫu là `customer@minishop.demo` và `admin@minishop.demo`, mật khẩu lấy từ biến seed do bạn tự đặt.

Sprint Q1 tính năng 1: Marketing Script Manager đã có model MongoDB, API Express, trang `/admin/marketing`, CRUD Server Actions, script runtime trong root layout và preview bằng cookie một giờ. Seed thêm Facebook Pixel, GTM và Hotjar ở trạng thái tắt với ID provider giả. Sau thay đổi này, `npm run build` của FE và BE thành công trên Node.js 22.18.0. Theo yêu cầu riêng của người dùng ở lượt sau, Docker Compose local đã được khởi động và seed dữ liệu mẫu vào MongoDB local; chưa deploy.

Sprint Q1 tính năng 2: User có phone/addresses và role CUSTOMER/ADMIN, Order có shippingStatus/trackingNumber. Đã thêm API account/admin orders, trang tài khoản có sidebar, hồ sơ, địa chỉ, lịch sử/chi tiết đơn; admin có danh sách/chi tiết đơn và trang xem sản phẩm. Seed khai báo 3 user QA (`Minishop@123`) và 8 đơn theo mã ổn định. Build FE/BE thành công; dữ liệu đã được seed vào MongoDB Docker local trong quá trình cập nhật tính năng 3. Chưa kiểm thử luồng nghiệp vụ hoặc deploy.

Sprint Q1 tính năng 3: FE có prefix `/us`, `/eu`, `/vn`, cookie region, rewrite host từ `REGION_HOSTS`, proxy ảnh supplier và redirect partner có UTM/`dest` override. BE có Partner model, public GET theo ID, 3 partner seed và ảnh supplier mẫu. Build FE/BE thành công trên Next.js 15.5.15; Docker Compose local đã được build lại, khởi động và seed. Chưa chạy QA cho tính năng 3, chưa deploy. Cần đặt `REGION_HOSTS` trước build nếu dùng custom domain và thay tracking URL placeholder của partner.

Sprint Q1 tính năng 4: FE gán cookie A/B/C và device từ User-Agent, thêm PLP `/products`, hero/grid theo variant và badge footer. Tám sản phẩm seed hiện có là dữ liệu QA. Frontend production build thành công trên Next.js 15.5.15 và container FE local đã được cập nhật; chưa chạy test hoặc QA. Page đọc cookie ở server nên render theo request, không thể dùng full-route cache chung. Backend không đổi.

Sprint Q1 tính năng 5: BE có Cart MongoDB cho user, JWT cookie ký cho guest, Coupon model/rules engine, cart API và product search API; checkout tính lại discount và lưu vào Order. FE chuyển giỏ sang Server Actions, có thêm/xóa coupon, tìm kiếm PLP và admin product picker. Seed thêm 8 coupon thuộc bốn loại. Production build FE/BE thành công trên Next.js 15.5.15; Docker Compose local đã được build lại và seed 8 coupon. Chưa chạy test hoặc QA. Hướng dẫn QA nằm trong README.

Lab CVE (môn bảo mật): FE nâng lên Next.js 15.5.15 để tái hiện đủ 5 CVE: 44580 (XSS `beforeInteractive`), 44575 (bypass middleware qua `.rsc`), 64645 (SSRF qua rewrite `?host=`), 44576 (cache poisoning RSC) và 64641 (DoS Server Actions O(n²)). Đã chạy cả 5 script trong `lab/` trên máy local và ghi kết quả vào [lab-cve-reproduction.md](lab-cve-reproduction.md); hướng dẫn khai thác từng bước nằm trong [lab-attack-guide.md](lab-attack-guide.md). Lab chỉ bật qua `LOCAL_CVE_MODE=1`/`seed:lab`/`*:study`; build và cấu hình Render thông thường không bật. Các script lab là harness tái hiện, không phải test suite. **Chưa deploy, chưa chạy trên Render/Atlas.**

Còn lại cho người dùng: tạo Atlas và hai Web Service Render theo [deployment.md](deployment.md); điền `JWT_SECRET`, mật khẩu seed, `API_BASE_URL`, `CORS_ORIGINS`; seed một lần; **không dùng Next 15.5.15 cho môi trường public** (nâng `>=15.5.21` và tắt lab mode nếu deploy thật).
